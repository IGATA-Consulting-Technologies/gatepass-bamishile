How to set up a guard's phone
  1. Copy the gate link above
  2. Send it to the guard's WhatsApp
  3. Guard opens the link in their phone browser
  4. Guard taps browser menu → Add to Home Screen
  5. GatePass installs as an app icon — no app store needed
  6. Guard opens the icon at the start of every shift
